# Jaakh Baba Cricket Pratiyogita - Season 6

Tournament website for the village cricket tournament at Girls School Ground, Shimla, Khetri (Jhunjhunu, Rajasthan).

Edit the `CONFIG` and `SEEDS` blocks near the top of the script in `index.html` to change dates, the CricHeroes live link, the organisers' WhatsApp number and seeded teams.
